Cómo funciona el juego:
Suma vertical real
Se muestran dos números de tres cifras alineados como en el cuaderno.
Paso a paso (algoritmo correcto)
Primero se resuelve la columna de las unidades
Luego las decenas (incluyendo la llevada)
Por último las centenas
El jugador debe escribir:
El dígito que va abajo
La llevada (0, 1 o 2)

Sistema de niveles
Nivel 1: pocas llevadas (más fácil)
Niveles siguientes: más llevadas y números más altos
Cada nivel requiere completar varias sumas
Subes de nivel automáticamente

Elementos del juego
❤️ 3 vidas
⭐ Puntuación
Barra de progreso del nivel
Pistas cuando las necesitas
Feedback inmediato explicando por qué está bien o mal
Estrellas al completar cada nivel

Interfaz en español y adaptada a móvil/tablet.
Consejos de uso:
Puedes pulsar Enter para comprobar la respuesta.
Al escribir el dígito, el cursor salta automáticamente a la casilla de la llevada.
Si te equivocas, pierdes una vida y te explica el error.
El objetivo es interiorizar el algoritmo de la suma con llevadas de forma visual y progresiva.
